마음안부 앱 — 설치와 업그레이드 방법

※ 고객 이름·전화번호는 인터넷에 올라가지 않습니다.
  아래에서 올리는 것은 앱 프로그램 파일뿐이고, 고객 정보는 아내분 휴대폰 안에만 저장됩니다.

────────────────────────────
[처음 한 번만] 무료 웹 주소에 앱 올리기 (GitHub Pages, PC에서 하시면 편합니다)
────────────────────────────
1. github.com 에 들어가 무료 회원가입
2. 오른쪽 위 + 버튼 → New repository
   - Repository name: maeum-anbu
   - Public 선택 → Create repository
3. 화면의 "uploading an existing file" 링크 클릭
   → 이 폴더의 파일 6개를 모두 끌어다 놓기
     (index.html, version.json, manifest.json, icon-192.png, icon-512.png, apple-touch-icon.png)
   → 아래 Commit changes 버튼
4. 저장소 위쪽 Settings → 왼쪽 Pages
   → Branch 에서 main 선택, 폴더는 / (root) → Save
5. 1~2분 뒤 아래 주소가 앱 주소가 됩니다
   https://(GitHub 아이디).github.io/maeum-anbu/

────────────────────────────
[아내분 휴대폰] 홈 화면에 설치
────────────────────────────
- 갤럭시: 크롬으로 위 주소 열기 → 오른쪽 위 ⋮ → '홈 화면에 추가'(또는 '앱 설치')
- 아이폰: 사파리로 위 주소 열기 → 아래 공유 버튼 → '홈 화면에 추가'
→ 홈 화면에 '마음안부' 아이콘이 생깁니다.

────────────────────────────
[나중에 기능을 추가할 때] 업그레이드
────────────────────────────
1. Claude에게 새 기능을 요청하면 새 index.html 과 version.json 을 받습니다.
2. GitHub 저장소 → Add file → Upload files → 두 파일을 끌어다 놓고 Commit changes
   (같은 이름이라 자동으로 덮어써집니다)
3. 10분쯤 기다린 뒤, 앱의 설정 탭 → '업그레이드 안내 문자'에서
   '문구 복사'(카카오톡에 붙여넣기) 또는 '문자로 보내기'를 눌러 아내분께 보냅니다.
   → 아내분이 링크만 누르면 바로 업그레이드됩니다.
     · 카카오톡에서 누르면 휴대폰 브라우저로 자동으로 넘어가서 열립니다.
     · 아이폰은 링크를 연 뒤 홈 화면의 마음안부 아이콘을 누르면 적용됩니다.
   안내 문자 없이도, 아내분이 앱을 열면 위쪽에 '새 버전 · 업그레이드' 알림이 뜹니다.
   → 업그레이드 버튼 한 번이면 끝. 앱을 지우거나 다시 설치할 필요가 없고,
     고객 목록과 인사말도 그대로 남아 있습니다.
   (알림이 안 보이면 설정 탭 → '업데이트 확인')
